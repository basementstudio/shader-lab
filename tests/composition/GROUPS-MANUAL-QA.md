# Editor groups — manual check

Use the latest V3 group-drag branch/preview (stacked on #157). This checks group organization and persistence.

1. Create a background, a photo, and a halftone effect above the photo. Select the photo and halftone with Cmd/Ctrl-click, then use **Group selected layers** in the Layers header (or Cmd/Ctrl+G). The effect should affect the photo; the background stays outside the group. A layer added while the group is selected should enter that group.
2. Double-click the group name to rename it. Collapse/expand its chevron; hide/show it and adjust its opacity and Blend in Properties. Children retain their own visibility/opacity settings.
3. Drag a layer handle onto the center of a group header: the group highlights and the status names the destination. Drop to move it into that group; a collapsed destination opens. Drop at the top/bottom of a row to insert before/after it at that row’s level. The insertion line shows the actual destination; placing a layer after a group places it after all of its children. Move the pointer left into the parent gutter to outdent, including when the scene contains only one group. Groups move with their complete subtrees. Escape or release outside the list cancels. Verify undo/redo for both order and membership. **Move up/down** in the layer menu and the **Group** selector in Properties remain keyboard alternatives.
4. Duplicate the group, delete the copy, and undo/redo. Try **Ungroup** in its menu (or Cmd/Ctrl+Shift+G). Undo should restore the group and its children. Ungroup removes the group's own opacity/blend/visibility contribution, so its appearance can change.
5. Save a `.lab` file, reopen it, and compare group names, order, collapse state, visibility, opacity, and any animated child/group properties. Export PNG and compare it with the preview. If using shader export, the config should retain group layers and child `parentId` references.
6. On mobile, open Layers and use a handle to drag into/out of a group. Drag near the top/bottom of a long list to scroll it. Ordinary touch scrolling away from the handles should still work.

Limits: eight group levels; grouping selections must share a parent (selecting a group also selects its subtree for group/duplicate/delete operations). A handle moves one layer or an entire group subtree. Drops into the dragged subtree, locked destinations, or beyond eight group levels are rejected. New saves use project version 7 and need this V3 build to reopen; older projects remain supported. Group masks and transparent scene/export backgrounds are separate work.
